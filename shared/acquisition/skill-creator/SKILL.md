# skill-creator

Creates new SKILL.md packages after checks.

## What it is
An acquisition skill that helps bootstrap new portable skills. It scaffolds the basic structure, runs initial validation, and prepares the package for governance review.

## How to use it
1. Use via Console or Builder when you identify a missing capability.
2. Provide a name and high-level description.
3. It generates a starter SKILL.md.
4. Then use the Builder to flesh it out, validate, and promote.

Part of the self-improving loop of the lab.
