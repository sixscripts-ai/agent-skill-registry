# Librarian: Console

Using the Console for aiskill commands, natural language prompts, and talking directly to Librarian.

## What it is
The direct interface to the simulated (or real) agent runtime. Lets you speak the native language of the lab.

## How to use it
- Type commands like 'aiskill doctor', 'aiskill list', or free-form prompts.
- Use the Presets for common safe operations.
- View structured output, exit codes, and gate results for dangerous commands.
- Ask "explain X" or "librarian how do I..." for in-console help.

This skill provides the knowledge for explaining the Console.
