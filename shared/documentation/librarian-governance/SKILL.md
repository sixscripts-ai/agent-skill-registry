# Librarian: Governance

The T1–T4 trust model, security gates, and when human approval is required.

## What it is
Governance applies G1-G4 verification gates before execution. T4 skills require human approval.

## How to use it
- Low trust tiers (T1) are auto-approved for safe operations.
- Higher tiers trigger gates and may require explicit approval.
- Use the Governance page to review recent blocked and passed commands.

This skill provides the knowledge for explaining governance features.
