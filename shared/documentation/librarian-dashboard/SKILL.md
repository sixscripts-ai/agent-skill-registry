# Librarian: Dashboard

The control tower and landing page for the entire Universal AI Skill Lab.

## What it is
Gives you instant visibility into registry health, skill lifecycle distribution, recent activity, and one-click access to the most common operations.

## How to use it
1. Check the four stat cards (Registry Health, Total Skills, Active Runtime, Last Eval).
2. Use the Quick Actions bar or the Actions menu for doctor/sync/eval/audit.
3. Review Recent Runs for the last simulated executions.
4. Click through to deeper sections (Registry, Builder, History, etc.).

This skill provides the knowledge for explaining the main dashboard view.
