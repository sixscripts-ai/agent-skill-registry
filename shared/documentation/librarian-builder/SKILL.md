# Librarian: Skill Builder

The place where you author new portable skills as SKILL.md packages.

## What it is
The lab is only as powerful as the skills you feed it. The Builder enforces structure, runs validation, deduplication, and governance before a skill can become active.

## How to use it
1. Fill name, tier (planning/functional/atomic/governance/acquisition/evaluation), trust tier (T1-T4), description.
2. Write the actual instructions in the SKILL.md body editor.
3. Run Validate → Dedupe → Governance (especially important for T4).
4. Save as Draft or promote to Active (which registers it).

This skill provides the knowledge for explaining the Skill Builder.
